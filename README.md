# 💻 Portfólio Pessoal

Portfólio de desenvolvedor criado para apresentar projetos, habilidades e evolução como estudante de **Desenvolvimento de Software Multiplataforma na FATEC**.

## 🚀 Tecnologias

- HTML5 — estrutura das páginas
- CSS3 — aparência, responsividade e animações
- JavaScript — interatividade, filtros e temas

## ✨ Funcionalidades

- Design responsivo para celular e computador
- Tema claro e escuro com preferência salva no navegador
- Cards de projetos com filtro por categoria
- Menu de navegação para dispositivos móveis
- Área de habilidades e contato

## 📂 Organização do projeto

```text
index.html
style.css
script.js
imagens/
  mesa.png
```

**Importante:** a capa do Mesa (`imagens/mesa.png`) deve ser adicionada ao repositório separadamente. Enquanto não estiver presente, o card exibe um título alternativo em CSS.

## ▶️ Como executar

Baixe os arquivos e abra `index.html` no navegador. Não é necessário instalar bibliotecas ou frameworks.

## 🎯 Objetivo

Praticar desenvolvimento web com HTML, CSS e JavaScript puro, documentando a evolução acadêmica e profissional.
